# Privacy Policy

Last updated: 01-09-2026

## Scope

This policy covers Health-Data M5, a personal single-user integration that imports Oura Ring data belonging to its sole operator and user.

## Who operates this

Kamil Mazur, an individual. Contact: ruzam92@gmail.com

## Whose data is processed

Only the operator's own data. This integration serves exactly one person, who is both the operator and the data subject. No other person can connect to it, and no other person's data is ever collected or processed.

## What data is collected

Data made available through the Oura API for the authorised scopes: personal information, daily summaries, heart rate, workouts, sessions, SpO2, tags, stress, heart health, and ring configuration.

## How it is collected

Through the Oura API, using OAuth 2.0 authorisation granted by the operator to the operator's own account. Access can be revoked at any time from the Oura account settings.

## How it is stored

In a local database file on a single computer under the operator's physical control. The storage location is not synchronised to any cloud service. Access credentials are stored locally with restricted file permissions.

## How it is used

For personal review of the operator's own health measurements over time, including automated processing performed locally on the same machine, and comparison against the operator's own laboratory results.

## Who it is shared with

No one. The data is not sold, rented, licensed, published, transmitted, or otherwise disclosed to any third party, any organisation, or any external service.

## Advertising and profiling

None. The data is not used for advertising, marketing, commercial targeting, or profiling of any kind.

## Retention and deletion

Data is retained locally for as long as the operator finds it useful for personal health tracking, and is deleted whenever the operator chooses. Because the operator is the only data subject, any deletion request is self-executed immediately.

## Revoking access

Authorisation can be withdrawn at any time in the Oura account settings, which immediately ends all further collection.

## Security

The data resides on a single machine protected by full-disk encryption and an account password. Credentials are stored outside any synchronised folder, with file permissions restricted to the operator's user account.

## Changes to this policy

Any change will be published in this file, with the date updated above.
