# Health-Data M5

A personal, single-user integration that imports my own Oura Ring data into a local health database running on my own computer.

## What it is

This is not a product, a service, or an application offered to anyone else. It is a set of scripts I run on my own machine to keep a long-term record of my own health measurements in one place, alongside data I export from Apple Health.

## Who can use it

Only me. There is no sign-up, no hosted instance, no user accounts, and no way for another person to connect. The integration authenticates against a single Oura account, which is my own.

## Where the data goes

Nowhere. All data stays on a single machine under my control. Nothing is uploaded, published, shared, sold, or transmitted to any third party.

## Purpose

Keeping a personal longitudinal record of my own health measurements, so I can look at them next to my own laboratory results over time.
